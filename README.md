# Hidden Lagoon — BUILD1500_DEMO_MASTER

## Köra på GitHub Pages
1. Lägg `BUILD1500_DEMO_MASTER.html` i repots rot (eller i `/docs`)
2. Settings → Pages → välj branch (och `/docs` om du la den där)
3. Klart — sidan körs på `https://ditt-repo.github.io/...`
